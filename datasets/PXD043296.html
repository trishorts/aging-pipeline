isobaric_peptide_q_psm_level warning
This multiplex search (MetaMorpheus 1.1.13) wrote its combined AllPeptides.psmtsv with each peptide's best PSM's PSM-level q-values, not peptide-level ones (MetaMorpheus #2941; QuantProject 071, corrected by v3.22). So `peptidoforms.best_q_value` and `best_q_value_notch` are PSM-level here, stored as written, and `peptidoforms_1pct` is a PSM-level filter: it passes more peptidoforms than results.txt's peptide-level count. The search's per-file _Peptides.psmtsv tables carry each file's own peptide-level q-values, which this bundle does not read; no file of this search gives a search-wide peptide-level q-value per peptide. `PeptideQuantification.tsv`'s values (DEF-TMT-PEP) are unaffected.
isobaric_unlabelled_peptides warning
212 row(s) of PeptideQuantification.tsv carry no multiplex label, with 3126 value(s), stored as written. A peptide with no label gives no reporter ions of its own, so these values are co-isolated interference (QuantProject 066, rule 4); a protein group's value can include them. Leave them out of peptide-level statistics. MetaMorpheus is to stop quantifying them (QuantProject 068, ruling 1). E.g. `[Common Biological:Acetylation on X]AAAAASGAGGAAGAGTGGAGPAGR`, `[Common Biological:Acetylation on X]AAAAVGAGHGAGGPGAASSSGGAR`, `[Common Biological:Acetylation on X]ADPWQEC[Common Fixed:Carbamidomethyl on C]MDYAVTLAR` and 209 more.
